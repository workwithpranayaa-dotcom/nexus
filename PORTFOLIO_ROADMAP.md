# NEXUS — Autonomous Incident Intelligence Platform

## What this project demonstrates
Production-style SRE platform starter: event ingestion, incident correlation, service graph, anomaly scoring, WebSocket-ready dashboard architecture, and AI investigation hooks.

## Interview demo sequence

1. Show the problem.
2. Trigger a realistic event.
3. Show the system processing it.
4. Open the internal event/trace view.
5. Explain one non-trivial architectural decision.
6. Demonstrate failure/recovery or scenario comparison.
7. Show tests and observability.
